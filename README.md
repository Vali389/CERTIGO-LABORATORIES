# CERTIGO-LABORATORIES

Official website and web platform for Certigo Laboratories Pvt Ltd, Visakhapatnam.

Quality testing for food, water, and microbiology, along with student learning programmes, internships, and BSc/MSc academic projects.

## Tech Stack
- **Framework**: TanStack Start (React 19, TypeScript)
- **Styling**: Tailwind CSS & Vanilla CSS design system
- **Routing**: TanStack Router (file-based routing)
- **Icons**: Lucide React
- **UI Components**: Radix UI

## Development

```sh
npm install --legacy-peer-deps
npm run dev
```

Visit [http://localhost:8081](http://localhost:8081) to view the application locally.
